# Contributing to InFabric

Thank you for your interest in contributing to InFabric!

We value human-driven contributions and collaboration. In alignment with Codeberg's FLOSS principles, we have a strict policy against autonomous AI-generated pull requests (often referred to as "AI slop").

## AI Policy

1. **No Autonomous AI PRs:** We do not accept pull requests that are entirely generated by AI without significant human oversight and understanding.
2. **Human Understanding:** You must fully understand and be able to explain any code you submit. If you use AI as a pair-programmer, you are responsible for the code it suggests.
3. **Quality over Quantity:** Focus on meaningful, well-tested, and maintainable contributions rather than generating large volumes of code.
4. **Backward Compatibility:** When dealing with game data, preserve backward compatibility. Use DataFixers or migrations to ensure old worlds don't break.

By submitting a pull request, you confirm that you have read and agree to these terms, and that the code represents your deliberate, human intent.

## Getting Started

1. Fork the repository.
2. Create a feature branch.
3. Make your changes and test them thoroughly.
4. Submit a pull request with a descriptive summary of your changes and why they are necessary.
